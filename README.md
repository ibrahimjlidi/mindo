# Mindo

Boutique en ligne statique pour Mindo, avec catalogue de produits, panier et commande via WhatsApp.

## Utilisation

Ouvrez `mindo-images.html` dans un navigateur. Les photos et les polices nécessitent une connexion Internet.

Les commandes sont préparées dans WhatsApp pour le numéro `+216 23 844 641`. Le client vérifie et envoie lui-même le message.
